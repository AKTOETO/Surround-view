## Первое чтение

1. First Principles: системы координат и матрица камеры; OpenCV calibration и fisheye — сразу проверить на контрольных точках.
2. TI Surround View и calibration — выписать поверхность, входы, предварительные вычисления и ограничения.
3. Документация Авроры — получить проверенный список API и зависимостей для конкретного устройства.
4. OpenGL ES/EGL и Qt scene graph — проверить первый FBO и представление кадра.
5. Zhang и Kannala–Brandt — связать работающий прототип с математической моделью.
6. Работы по контролю extrinsics и NIST — сформировать независимые тесты и программу опытов.

Для каждой прочитанной работы добавить дату, версию/DOI, страницы, краткий вывод и отличие от проекта в её запись. Сохранять подтверждённые результаты отдельно от гипотез. Версия OpenCV 5 alpha, GLSL ES 3.20 и инструкции Авроры 4.0.1 в исходном списке не задают версии зависимостей проекта.
