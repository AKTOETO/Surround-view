# Требования к sv-configurator

Требование охватывает offline-подготовку/отчёт и server-side применение проверенной калибровки. Сегодня есть offline OpenCV tools, а calibration job API сервера отдельно принимает training/held-out observations и атомарно применяет прошедший gate кандидат. Это ещё не общий runtime ConfigService: обычная смена source/surface/fusion требует правки серверного config и перезапуска. Методика: [[research/CALIBRATION]]. Формат: [[requirements/CONFIGURATION]].

| ID | Приоритет | Условие и поведение | Приёмка | Задача |
|---|---|---|---|---|
| CAL-F-001 | MUST | Утилита принимает шаблон, четыре набора наблюдений и их метаданные; сохраняет происхождение | T-CAL-001: известные точки, размеры и система координат; неверные данные отклонены | R2 |
| CAL-F-002 | MUST | Оценивает intrinsics и внешние преобразования относительно автомобиля выбранной моделью | T-CAL-002: E-CALIB-01, синтетическая истина и независимые наблюдения | R2 |
| CAL-F-003 | MUST | Отчёт отделяет обучающую и проверочную репроекцию, ошибки по камерам/видам и вырожденные случаи | T-CAL-003: контрольные выборки не входят в оптимизацию | R2, R6 |
| CAL-F-004 | MUST | Экспортирует цельную валидированную версию с calibration_id/hash, разрешением и ссылкой на отчёт | T-CAL-004: сервер принимает подходящую версию и отвергает несовместимую | R2, R5 |
| CAL-F-005 | MUST | Диагностика возвращает состояние, условия пригодности, камеры-кандидаты и показатель; не заменяет параметры автоматически | T-CAL-005: E-DRIFT-01, ложные тревоги и INDETERMINATE | R4 |
| CAL-F-006 | MUST | Повторная калибровка сохраняет старую версию и количественное сравнение восстановления | T-CAL-006: E-RECOVERY-01, корректный экспорт и отказ от плохой новой версии | R4, R6 |

Первый интерфейс может быть CLI. GUI для исключения наблюдений и просмотра отчёта добавляется после работающей процедуры. Ceres/Eigen — кандидаты для offline-вычислений; их использование не делает их обязательными зависимостями сервера на Авроре. Схемы и CLI пока являются проектными контрактами.
