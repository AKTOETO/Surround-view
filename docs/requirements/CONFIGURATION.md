# Требования к конфигурации и калибровке

## Ответственность

`CFG` описывает все параметры, которые должны изменяться без перекомпиляции: автомобиль, камеры, калибровку, bowl-поверхность, входные потоки и параметры рендера.

## Требования

| ID | Приоритет | Требование | Приемка |
|---|---|---|---|
| CFG-F-001 | MUST | Конфигурация должна иметь явную версию schema. | Сервер выводит версию при запуске и отклоняет несовместимую. |
| CFG-F-002 | MUST | Конфигурация должна содержать размеры автомобиля и начало его системы координат. | Значения доступны geometry generator. |
| CFG-F-003 | MUST | Для каждой камеры должны задаваться ID, resolution, pixel format, положение и ориентация. | Сервер создает ровно описанные camera inputs. |
| CFG-F-004 | MUST | Для каждой камеры должны задаваться intrinsics и модель distortion. | Projection model выбирается из конфигурации. |
| CFG-F-005 | MUST | Для bowl-поверхности должны задаваться рабочие размеры, высота, кривизна и плотность сетки. | Изменение параметра меняет результат генератора. |
| CFG-F-006 | MUST | Конфигурация должна задавать входные timeouts и политику stale frames. | Политика применяется в runtime и видна в telemetry. |
| CFG-F-007 | MUST | Все длины должны иметь единицы, а углы — определенное представление. | Validator отклоняет неизвестные или недопустимые units. |
| CFG-F-008 | MUST | Конфигурация должна валидироваться до запуска pipeline. | Ошибки содержат путь параметра и причину. |
| CFG-F-009 | MUST | Конфигурация не должна содержать исполняемый код или shader source. | Parser принимает только описательные данные. |
| CFG-F-010 | SHOULD | Должен существовать инструмент печати эффективной конфигурации после defaults. | Итоговая конфигурация сохраняется для эксперимента. |

## Минимальная структура

```yaml
schema_version: 1
vehicle:
  dimensions_m: {length: 4.6, width: 1.8, height: 1.5}
  coordinate_system: vehicle
cameras:
  - id: 0
    resolution: {width: 1280, height: 720}
    pixel_format: RGB8
    pose: {position_m: [0, 0, 1.2], orientation_rpy_rad: [0, 0, 0]}
    projection: {model: fisheye, intrinsics: {}, distortion: {}}
surface:
  type: bowl
  width_m: 8.0
  length_m: 10.0
  height_m: 1.0
  curvature: 0.5
  grid: {rows: 256, columns: 256}
runtime:
  target_fps: 30
  stale_timeout_ms: 100
```

Это пример схемы, а не окончательный формат. До реализации зафиксировать JSON Schema или эквивалентное описание.
