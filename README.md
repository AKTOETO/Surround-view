# Surround View

**Тема:** «Исследование и разработка системы отображения и методик калибровки функции интерактивного кругового обзора ТС для ОС Аврора».

Система формирует интерактивное представление по изображениям четырёх широкоугольных камер; работа включает первоначальную калибровку, диагностику смещения и проверку на целевом устройстве.

В репозитории есть рабочий Linux/replay-прототип: C++17, EGL/OpenGL ES, сервер Boost.Asio, клиент Qt Quick и Python-инструменты калибровки. Подготовлены главы 1–4 и предварительное заключение; первые измерения выполнены на Mesa и RTX 5070 Ti. Реальные камеры и перенос на Аврору остаются следующими этапами.
