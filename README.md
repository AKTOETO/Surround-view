# Surround View

**Тема:** «Исследование и разработка системы отображения и методик калибровки функции интерактивного кругового обзора ТС для ОС Аврора».

Система формирует интерактивное представление по изображениям четырёх широкоугольных камер; работа включает первоначальную калибровку, диагностику смещения и проверку на целевом устройстве.

Рабочий Linux-прототип 0.6.0 включает plane/bowl и замкнутые купол, цилиндр и куб с отдельным полом и виртуальной камерой внутри. Фотографические fisheye-входы проходят через реальный OpenCV; OpenGL ES проецирует их на купол и пол, а ненаблюдаемые области имеют сплошной фон. Подготовлены offline RPM-профили; целевая сборка/установка Авроры и реальные камеры ещё не проверены.

Добавлен процедурный 3D-стенд Blender с автомобилем, четырьмя разнесёнными камерами и заданной траекторией. Экспортированные кадры поступают в сервер через replay worker либо четыре Unix/TCP-входа виртуальных камер. Интерактивное вождение и прямой аппаратный ввод остаются в плане. Мир хранится в Git как скрипты и готовый `.blend` в `assets/scenes/metric-street/`, без Git LFS.

Реализованы edge-feather, angular-feather и выбор камеры по углу; добавлены карты покрытия/весов и воспроизводимое сравнение пяти поверхностей на Blender-записи. Первый screening показывает заполнение оболочек; метрики качества швов и temporal stability ещё предстоит измерить. См. [режимы рендера](docs/engineering/RENDERING.md). См.
