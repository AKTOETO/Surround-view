# Surround View

**Тема:** «Исследование и разработка системы отображения и методик калибровки функции интерактивного кругового обзора ТС для ОС Аврора».

Система формирует интерактивное представление по изображениям четырёх широкоугольных камер; работа включает первоначальную калибровку, диагностику смещения и проверку на целевом устройстве.

Рабочий Linux-прототип 0.3.0 включает bowl для аналитических сравнений и отдельную сцену «пол + купол» с виртуальной камерой внутри оболочки. Фотографические fisheye-входы проходят через реальный OpenCV; OpenGL ES проецирует их на купол и пол, а ненаблюдаемые области имеют сплошной фон. Подготовлены offline RPM-профили; целевая сборка/установка Авроры и реальные камеры ещё не проверены.

Начат сравнительный обзор способов слияния кадров четырёх камер и mesh-носителей (купола, bowl, цилиндра, куба). Сейчас используется прямая fisheye-проекция с feather-весами; измерения альтернатив и качества швов ещё не выполнены. См. [исследование методов](docs/research/PROJECTION_AND_STITCHING.md) и [обновлённый план](TODO.md).
